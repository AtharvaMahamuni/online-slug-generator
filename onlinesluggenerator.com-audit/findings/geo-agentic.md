# AI Search Readiness (GEO & Agentic SEO) Findings

## Discovery Files
- `robots.txt`: Explicitly differentiates search crawlers from model scrapers.
- `robots-ai.txt`: Mirrors crawler groups for AI agents.
- `llms.txt`: Structured Markdown summary citing core pages and multilingual endpoints.
- `llms-full.txt`: Extended technical documentation for LLMs.
- `ai.txt` & `ai.json`: Machine-readable crawler policy definitions.
- `brand.txt`: Author and brand name styling rules.
- `faq-ai.txt`: Concise Q&A answers without synthetic schema markup.
- `identity.json`: Standalone JSON-LD graph matching site metadata.

## Agent Accessibility
- Keyboard accessible with skip-to-content links.
- ARIA live region announcements for copied slugs and state changes.
- Responsive viewport navigation tested down to 320x568.
